# 文献管理

‍

> 本文记录参考项目和当前项目定位。具体实现以子文档《实现方案》为准。

## 一、当前项目定位

脑出血 RAG 的文献管理系统固定为 **FastAPI + Vue 3 + PostgreSQL 的 Web 系统**，由两个独立仓库组成：

- ​`medical-knowledge-api`：端口 8001。
- ​`medical-knowledge-web`：端口 5173。

第一版 MVP 包含文献 CRUD、PDF 上传、DOI 元数据获取、文件夹/集合、PDF 转 Markdown、章节恢复、分块和 Chunk 查看。

## 二、解析技术

- 常规 PDF：MinerU。
- 复杂版式和表格：Docling。
- 扫描件：OCR 后进入 MinerU/Docling。
- PDF.js：浏览器阅读与定位。

参考项目仅用于学习，不改变本项目的 PostgreSQL、独立前后端仓库、MinerU/Docling 和 MVP 约束。

## 四、核心领域原则

- 文献元数据与附件分离。
- 内部主键使用 UUID，DOI 只用于规范化和去重。
- 一篇文献可以有多个附件和多个不可变解析版本。
- PDF 保存到文件系统或对象存储，数据库保存路径、哈希和元数据。
- 作者保留顺序，支持个人作者和机构作者。
- 文件夹/集合与文献是多对多关系。
- Chunk 保存页码、字符位置和文档版本，支持引用回溯。

## 五、开发顺序

1. PostgreSQL、Alembic 和文献数据模型。
2. 文献 CRUD 与文件夹。
3. PDF 上传和 SHA256 去重。
4. DOI 与外部元数据。
5. MinerU/Docling/OCR。
6. 文档版本、章节和 Chunk。
7. Vue 文献库、上传和解析状态界面。
8. PDF 阅读、批注和引用导出。
